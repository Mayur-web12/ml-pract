# Practical No. 3(a): Simple Linear Regression

# 1. Aim
To implement Simple Linear Regression, interpret the model coefficients,
make predictions, and evaluate its performance using Mean Squared Error (MSE) and R-squared score.

# 2. Algorithm / Procedure
1. Import NumPy, Matplotlib, and Scikit-learn libraries.
2. Create input (X) and output (y) datasets.
3. Create a Linear Regression model.
4. Train the model using the fit() method.
5. Predict output using the predict() method.
6. Calculate intercept, coefficient, MSE, and R-squared score.
7. Predict the output for a new input value.
8. Plot actual data and the regression line.

# Program
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# Dataset
X = np.array([1, 2, 3, 4, 5, 6, 7, 8]).reshape(-1, 1)
y = np.array([2, 4, 5, 4, 6, 7, 8, 9])

# Create and train model
model = LinearRegression()
model.fit(X, y)

# Prediction
y_pred = model.predict(X)

# Coefficients
print("Intercept:", round(model.intercept_, 2))
print("Coefficient:", round(model.coef_[0], 2))

# Regression Equation
print("\nRegression Equation:")
print(f"y = {model.intercept_:.2f} + {model.coef_[0]:.2f}x")

# Performance
mse = mean_squared_error(y, y_pred)
r2 = r2_score(y, y_pred)

print("\nMSE:", round(mse, 2))
print("R-squared:", round(r2, 2))

# New Prediction
new_X = np.array([[10]])
prediction = model.predict(new_X)

print("\nPrediction for X = 10:", round(prediction[0], 2))

# Chart
plt.scatter(X, y, color="blue", label="Actual Data")
plt.plot(X, y_pred, color="red", linewidth=2, label="Regression Line")

plt.xlabel("X")
plt.ylabel("Y")
plt.title("Simple Linear Regression")
plt.legend()
plt.grid(True)
plt.show()

# Expected Output
Intercept: 1.0
Coefficient: 0.95

Regression Equation:
y = 1.00 + 0.95x

MSE: 0.42
R-squared: 0.92

Prediction for X = 10: 10.52

# Result
Thus, Simple Linear Regression was successfully implemented,
predictions were made, and model performance was evaluated using MSE and R-squared.
