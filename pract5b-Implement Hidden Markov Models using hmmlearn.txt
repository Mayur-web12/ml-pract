# Practical No. 5(b) – Implement Hidden Markov Models using hmmlearn

# 1. Aim
To implement and demonstrate a Hidden Markov Model (HMM) 
using the hmmlearn library for predicting hidden states 
and generating observation sequences.

#  Algorithm / Procedure
1. Import NumPy and the hmmlearn library.
2. Create a sample observation sequence.
3. Initialize the Hidden Markov Model with two hidden states.
4. Train the model using the observation data.
5. Display the transition, emission, and start probability matrices.
6. Predict the hidden states.
7. Generate a new observation sequence and corresponding hidden states.

#program


# 1. Import libraries
import numpy as np
from hmmlearn import hmm

# 2. Create observation data
# 0 = Walk, 1 = Shop, 2 = Clean

observations = np.array(
    [[0, 1, 2, 1, 0, 1, 2, 1, 0, 2]]
).T

# 3. Initialize HMM
model = hmm.MultinomialHMM(
    n_components=2,
    n_trials=1,
    n_iter=100,
    random_state=42
)

# 4. Fit the model
model.fit(observations)

# 5. Print model parameters
print("Transition Matrix:")
print(model.transmat_)

print("\nEmission Matrix:")
print(model.emissionprob_)

print("\nStart Probabilities:")
print(model.startprob_)

# 6. Predict hidden states
hidden_states = model.predict(observations)

print("\nPredicted Hidden States:")
print(hidden_states)

# 7. Generate a new sequence
X, Z = model.sample(10)

print("\nGenerated Observation Sequence:")
print(X.ravel())

print("Corresponding Hidden States:")
print(Z)

# Result
The Hidden Markov Model was successfully implemented using the hmmlearn library. 
The model was trained on observation data, and hidden states and a new observation sequence were generated.
