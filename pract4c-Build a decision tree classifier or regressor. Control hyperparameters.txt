# Practical No. 4(c): Decision Tree Classifier

# 1. Aim
To implement a Decision Tree Classifier, control tree depth to reduce overfitting,
evaluate accuracy, and visualize the decision tree.

# Algorithm / Procedure
1. Import the required libraries.
2. Create a sample dataset.
3. Separate input features and target labels.
4. Split the dataset into training and testing sets.
5. Create a Decision Tree Classifier with maximum depth of 3.
6. Train the model and predict test samples.
7. Calculate model accuracy.
8. Visualize the decision tree.

#Program
# DECISION TREE CLASSIFIER

import pandas as pd
import matplotlib.pyplot as plt

from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, plot_tree
from sklearn.metrics import accuracy_score

# 1. Create Sample Dataset
data = {
    'sepal_length': [5.1, 4.9, 5.8, 6.0, 6.3, 5.0, 5.5, 6.7, 6.5, 5.7],
    'sepal_width': [3.5, 3.0, 2.7, 3.4, 3.3, 3.6, 2.8, 3.1, 2.8, 2.5],
    'petal_length': [1.4, 1.4, 4.1, 4.5, 5.0, 1.5, 4.5, 5.6, 5.2, 4.0],
    'petal_width': [0.2, 0.2, 1.3, 1.5, 2.0, 0.2, 1.5, 2.4, 2.0, 1.2],
    'species': [
        'setosa', 'setosa', 'versicolor', 'versicolor',
        'virginica', 'setosa', 'versicolor', 'virginica',
        'virginica', 'versicolor'
    ]
}

df = pd.DataFrame(data)

# 2. Separate Features and Target
X = df.drop('species', axis=1)
y = df['species']

# 3. Split Dataset
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# 4. Build Decision Tree Classifier
tree = DecisionTreeClassifier(
    max_depth=3,
    random_state=42
)

tree.fit(X_train, y_train)

# 5. Make Predictions
y_pred = tree.predict(X_test)

print("Actual Labels:")
print(y_test.values)

print("\nPredicted Labels:")
print(y_pred)

# 6. Calculate Accuracy
accuracy = accuracy_score(y_test, y_pred)

print(f"\nModel Accuracy: {accuracy * 100:.2f}%")

# 7. Visualize Decision Tree
plt.figure(figsize=(12, 8))

plot_tree(
    tree,
    feature_names=X.columns,
    class_names=tree.classes_,
    filled=True,
    rounded=True
)

plt.title("Decision Tree Visualization")
plt.show()

# Expected Output
The program displays:
- Actual labels
- Predicted labels
- Model accuracy
- Decision tree visualization
The accuracy is calculated during execution. 
The graph shows decision conditions, branches, and predicted classes.

# 5. Result
Thus, the Decision Tree Classifier was successfully implemented,
its depth was controlled using the max_depth parameter, and the tree was visualized.
