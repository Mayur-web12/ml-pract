
Practical No. 2(a): FIND-S Algorithm
# Aim
To implement the FIND-S algorithm to find the most specific hypothesis 
from a given set of positive training examples using a CSV dataset.

# Algorithm / Procedure
1. Import the CSV library.
2. Create a training dataset and save it as tennis.csv.
3. Read the training data from the CSV file.
4. Initialize the hypothesis with the most specific values (0).
5. Consider only positive examples where the target is True.
6. Compare each attribute and replace different values with ?.
7. Display the final most specific hypothesis.

# Program
import csv

# Create Training Dataset
data = [
    ['Sunny', 'Warm', 'Normal', 'Strong', 'Warm', 'Same', 'True'],
    ['Sunny', 'Warm', 'High', 'Strong', 'Warm', 'Same', 'True'],
    ['Rainy', 'Cold', 'High', 'Strong', 'Warm', 'Change', 'False'],
    ['Sunny', 'Warm', 'High', 'Strong', 'Cool', 'Change', 'True']
]

# Save Dataset to CSV
with open("tennis.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(data)

# Read CSV File
with open("tennis.csv", "r") as f:
    data = list(csv.reader(f))

# Initialize Hypothesis
h = ['0'] * (len(data[0]) - 1)

# FIND-S Algorithm
for row in data:
    print(row)

    if row[-1] == "True":
        for i in range(len(h)):
            if h[i] == '0':
                h[i] = row[i]
            elif h[i] != row[i]:
                h[i] = '?'

print("Most specific hypothesis is:")
print([h])

# Result
Thus, the FIND-S algorithm was successfully implemented 
to find the most specific hypothesis from positive training examples.
